BananaForScale

object BananaForScale(source)

A real-size banana, 185 mm tip to stem, stood beside a device's model for scale. The model is bundled with the app, built from a CC0 drawing by scripts/models/banana_for_scale.py: Y up, in meters, standing on y = 0 with its labeled front facing +Z, like the flasher's models.
