Link copied to clipboard
fun runWhenDisconnected(onReady: () -> Unit)

Runs onReady now when the radio is disconnected. Otherwise, including while it sleeps or connects, asks first and, once confirmed, disconnects the radio the same way the Connections screen does, then runs onReady. The backup or restore binds to the device database active before the disconnect or, already disconnected, to the last device's; with no device database it does not proceed.
