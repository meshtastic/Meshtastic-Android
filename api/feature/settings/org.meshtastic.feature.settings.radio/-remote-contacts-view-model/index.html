RemoteContactsViewModel

class RemoteContactsViewModel(val destNum: Int, nodeRepository: NodeRepository, radioController: RadioController, ensureRemoteAdminSession: EnsureRemoteAdminSessionUseCase) : ViewModel(source)

Edits the node DB of destNum, a node this radio administers remotely: send a contact and favorite it, unfavorite, ignore, unignore and remove. Candidates come from the local node DB, since firmware has no admin request that lists a remote node DB.
