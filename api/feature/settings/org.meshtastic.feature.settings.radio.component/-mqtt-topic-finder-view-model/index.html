MqttTopicFinderViewModel

class MqttTopicFinderViewModel(reverseGeocoder: ReverseGeocoder, locationService: LocationService, mqttRootsRepository: MqttRootsRepository) : ViewModel(source)

Samples the broker for the root topics in use and builds the suggestions for where the user is. The radio's own fix comes first and the phone's location is the fallback, read only when permission is already granted.
