BaseMapViewModel

open class BaseMapViewModel(mapPrefs: MapPrefs, nodeRepository: NodeRepository, packetRepository: PacketRepository, radioController: RadioController, radioConfigRepository: RadioConfigRepository, notificationPrefs: NotificationPrefs, localeUnitsProvider: LocaleUnitsProvider, networkRepository: NetworkRepository) : ViewModel(source)

Shared base ViewModel for the map feature, providing node data, waypoints, map filter preferences, and traceroute overlay state.

Platform-specific map ViewModels (fdroid/google) extend this to add flavor-specific map provider logic.
