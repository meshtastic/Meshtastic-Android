trackRecency
Link copied to clipboard
fun trackRecency(times: List<Long?>): List<Float>

Where each point of an oldest-first track sits between its oldest and newest fix in time, from 0 to 1, so a burst of fixes after a quiet hour reads as recent and the quiet hour as old. Measured across the track's own span, so a track that is old throughout still fades from end to end. When any time is unknown (null or not positive) or every time is the same, the track fades by its order instead.
