feature-map/org.meshtastic.feature.map.tiles/MapTileCatalogue

MapTileCatalogue

object MapTileCatalogue(source)

The tile sources the app offers, independent of which engine draws them.

These are URL templates, zoom ranges and attribution strings — data, not rendering — but they lived in the MapLibre module, which the Google flavour cannot depend on. So the Google map offered four Google map types and nothing else, and a user who wanted USGS or Esri there had to type the tile URL in by hand as a custom source.
