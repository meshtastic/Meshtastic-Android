HudTarget

data class HudTarget(val subject: HudSubject, val bearingDeg: Double, val elevationDeg: Double, val distanceM: Double, val distanceText: String, val precisionHalfAngleDeg: Double?, val elevationSpreadDeg: Double, val elevationKnown: Boolean, val positionAgeSec: Long?, val focused: Boolean, val rise: HudRise? = null)(source)

A positioned node or waypoint as the HUD draws it. bearingDeg is magnetic, to match the camera pose, and precisionHalfAngleDeg spans the target's uncertainty circle widened by the phone's own fix accuracy, or is null when neither is known. elevationKnown is false when the target and the phone share no altitude frame, so the target sits level with the phone.
