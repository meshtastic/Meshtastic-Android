pinEdge
Link copied to clipboard
fun pinEdge(projected: ScreenPoint?, width: Float, yawDeg: Double, pitchDeltaDeg: Double, previous: PinEdge?): PinEdge

Where to pin a target that falls outside the view, chosen the way someone finds it: a target well to the side, or behind, pins to the side to turn toward (yawDeg, positive clockwise), and one roughly ahead pins top or bottom to tilt toward (pitchDeltaDeg, positive up). Choosing on the screen's own axes instead puts a node behind the user on the bottom edge while the camera points at the ground, which reads as inverted. previous holds through small wobbles: near SIDE_YAW_DEG and near straight behind, where the side would otherwise flip.

stackLevels
Link copied to clipboard
fun stackLevels(boxes: List<AngularBox>, gapDeg: Double, leaderRunDeg: Double = 0.0, maxLevel: Int = MAX_STACK_LEVEL): IntArray

How many rows each chip is lifted so none overlaps an earlier one, in list order. Computed from view angles rather than screen positions, so it holds still while the phone moves and changes only when the targets do. A lifted chip also steps aside by its half width plus leaderRunDeg, to the side leaderSide gives, so its leader leans rather than rising plumb; a chip that would need more than maxLevel rows gets OVERFLOW_LEVEL.
