SpatialModelTransform

class SpatialModelTransform(val frame: SpatialFrame, val baseElevation: Double, maxElevation: Double, verticalExaggeration: Double = 1.5, modelSize: Vec3 = Vec3(1f, 0.3f, 1f))(source)

Scales the local meters frame into the model: the box fits a footprint of about a meter and relief is exaggerated so a tabletop model still reads as hills.
