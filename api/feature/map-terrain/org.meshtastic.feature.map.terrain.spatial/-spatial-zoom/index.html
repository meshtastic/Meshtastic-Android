SpatialZoom

object SpatialZoom(source)

Zooming the spatial map into the geography. The table keeps its size; the circle it shows gets smaller around a center, and the terrain is rebuilt for it. Zoom 1 is the whole mesh.

While a zoom is waiting for its terrain, the built terrain is shown scaled and shifted toward what the new circle will show. offset is the new center's position on the current disk and scale how much bigger the new circle draws the ground, both in model units. The scale is held between 0.2 and the size where the terrain's edge reaches maxRadius, and the shift is cut so no part of the terrain goes past maxRadius (under the bezel).
