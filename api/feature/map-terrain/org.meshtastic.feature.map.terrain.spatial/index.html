SpatialFrame
Link copied to clipboard
data class SpatialFrame(val bounds: GeoBounds)

The local frame a spatial map is built in: meters from the center of a geographic box, with x east, y up and z south (north is away from a viewer standing south of the model). The box is small enough that a flat-earth conversion around its center is accurate to well under a meter, which is finer than any mesh position.

SpatialTerrainGeometry
Link copied to clipboard
class SpatialTerrainGeometry(source: SpatialHeightGrid, val transform: SpatialModelTransform, skirtDepth: Float = DEFAULT_SKIRT_DEPTH)

The terrain mesh plus the height field it was built from, in model units. The mesh is a disk inscribed in the box: a regular grid with the vertices outside the circle moved onto it, and a round skirt below the edge so the model reads as a solid table. Buffers are flat: positions and normals hold xyz triples, textureCoordinates uv pairs.
