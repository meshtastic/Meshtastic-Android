RangeCheckedHttpChannel

class RangeCheckedHttpChannel(url: URL) : UrlFileChannel(source)

A PMTiles channel over HTTP range requests that only accepts the bytes it asked for. A 200 that ignored the Range header and a 206 whose Content-Range names other bytes both throw IOException. An ETag that differs from the first one seen, or goes missing after it, and a 416 for a range that used to exist throw ArchiveChangedException. Only a 404 throws FileNotFoundException.
