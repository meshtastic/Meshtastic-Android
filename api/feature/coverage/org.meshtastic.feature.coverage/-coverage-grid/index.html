CoverageGrid

class CoverageGrid(val site: Site, val width: Int, val height: Int, val north: Double, val south: Double, val east: Double, val west: Double, val dbm: DoubleArray)(source)

Received signal strength on a regular lat/lon grid.

Coverage is drawn as filled iso-bands, which need a regular grid. Polar samples exported as GeoJSON Point features would be clustered by the map and render as a swarm of identical node markers.

NaN marks a cell that was not computed.
