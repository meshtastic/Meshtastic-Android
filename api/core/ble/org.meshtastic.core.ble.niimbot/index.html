class NiimbotPacket(val type: Int, val data: ByteArray)

One packet of the Niimbot label printer protocol, as the printer sends and receives it: 55 55 · type · length · data · checksum · AA AA, where the checksum XORs the type, the length and every data byte.

NiimbotPacketParser
Link copied to clipboard
class NiimbotPacketParser

Collects bytes from the printer's notifications and yields whole packets. A notification can carry part of a packet or several; bytes that don't start a packet are dropped until the next 55 55. A frame with a bad checksum or tail gives up only its first byte: the search resumes at its second 55, which may be the real head after a stray one.
