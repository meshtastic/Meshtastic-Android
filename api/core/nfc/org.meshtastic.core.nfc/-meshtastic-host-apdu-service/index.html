MeshtasticHostApduService

class MeshtasticHostApduService : HostApduService(source)

Presents the armed share URL as an NFC Forum Type 4 Tag, so a reader - another phone, a Flipper, any NDEF reader - can take a contact or channel by tapping this phone, with no physical tag.

Read-only by construction: the capability container advertises no write access and no write command is answered. Serves nothing unless NfcTagEmulation is armed, so an idle phone presents no tag at all.

Implements only what a Type 4 read needs: SELECT application, SELECT file, READ BINARY.
