PrefsStore

interface PrefsStore

The part of DataStore<Preferences> the prefs use; androidx.datastore.preferences publishes no wasmJs variant. nonWebMain's DataStorePrefsStore wraps a real DataStore, wasmJsMain's LocalStoragePrefsStore uses localStorage. The transform is not suspending, so no suspension point can fall between a read and its write.

fun DataStore<Preferences>.asPrefsStore(): PrefsStore

Adapts a real DataStore<Preferences> (android/jvm/iOS only — androidx.datastore.preferences has no wasmJs variant) to the platform-neutral PrefsStore. Every CorePrefsAndroidModule/DesktopPlatformModule call site that used to hand a DataStore<Preferences> straight to an asXDataStore() wrapper now inserts this adapter first: store(...).asPrefsStore().asXDataStore().
