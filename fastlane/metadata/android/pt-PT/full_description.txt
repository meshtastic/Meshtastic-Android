O Meshtastic permite utilizar dispositivos Android com rádios mesh de código aberto que funcionam sem depender da rede móvel ou da Internet. Esta aplicação é o principal cliente do projeto Meshtastic e permite gerir os seus dispositivos mesh e comunicar com outros utilizadores.

Para mais informações sobre o projeto Meshtastic, visite o nosso site: <a href="https://www.meshtastic.org">meshtastic.org</a>. O firmware dos dispositivos de rádio é um projeto de código aberto separado, disponível em: <a href="https://github.com/meshtastic/Meshtastic-device">https://github.com/meshtastic/Meshtastic-device</a>.
